=== OPTIONAL BACKGROUND MUSIC ===

To provide custom background music:
1. Place your MP3 file named "rakhi_theme.mp3" in this directory:
   public/audio/rakhi_theme.mp3

2. The application will automatically detect and play it when the user clicks the "MUSIC ON" button!

3. If no MP3 file is present, the website automatically uses its built-in Web Audio API Raag synthesizer to generate meditative ambient harp & drone sounds seamlessly!
